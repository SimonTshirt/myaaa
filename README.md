# MYA - Move Your Ass

A motivational iOS app that sends personalized notifications based on user goals.

## Overview

MYA (Move Your Ass) is a simple iOS application designed to help you stay motivated and focused on your goals. The app sends personalized motivational notifications at your preferred frequency.

## Features

- Set personal goals
- Customize notification frequency (hourly, daily, weekly)
- Receive motivational notifications tailored to your specific goals
- Easy-to-use interface

## Requirements

- iOS 14.0+
- Xcode 12.0+
- Swift 5.3+

## Getting Started

1. Clone this repository
2. Open `MYA.xcodeproj` in Xcode
3. Build and run the application on your device or simulator

## Project Structure

- **Models**: Data structures that represent the app's data
- **Views**: SwiftUI views that make up the user interface
- **ViewModels**: Classes that connect the views with the data models
- **Services**: Classes that handle specific functionality like notifications
